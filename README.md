# Sketch-to-AI-Art-Generator
An interactive application that converts user sketches into high-quality AI generated images using Stable Diffusion, ControlNet and BLIP. The system interprets drawings, generates prompts automatically, and produces styled outputs such as photorealistic, anime, or oil painting.
